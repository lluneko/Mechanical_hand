# Проект:
сайт, который позволяет изменять и просматривать статус кнопки на включение/выключение механической руки
## Как начать использование
1) Скачать файлы app.py и папку templates, положив в одну папку.
2) Запустить через любую среду разработки с утановленный языком python файл app.py.
3) Перейти по появивщейся ссылке на сайт.
## Доступные команды(пишутся в поисковой строке)
* '/' - главная страница при запуске
* '/status' - получить текущий статус
* '/status_on' - включить, изменить текущий статус
* '/status_off' - выключить, изменить текущий статус
